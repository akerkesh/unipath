# unipath

A web app that generates personalized 4-year academic plans for engineering students. Users input their major, minor, incoming credits, and preferences; the system produces a semester-by-semester schedule with AI-formatted explanations.

---

## Setup

```bash
# Clone the repo
git clone <repo-url>
cd unipath

# Install dependencies
npm install

# Run the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
